# For Graph Authors

This path is for users who want to build, edit, debug, and understand graphs in depth.

## Start Here

1. [Studio (GUI)](../getting-started/studio.md)
2. [PyStudio Guide](../pystudio/index.md)
3. [Node Atlas](../node-atlas/index.md)
4. [Scenarios](../scenarios/index.md)

## What You Will Use Most

- `PyStudio Guide` for editor workflow, lifecycle, schema editing, and sessions
- `Node Atlas` for the node-by-node release inventory
- `Modules` reference for canonical service and operator specs
- `Scenarios` for end-to-end runnable examples

## Suggested Learning Order

1. Learn the editor workflow in `Studio` and `PyStudio Guide`
2. Open a scenario graph and identify the main services/operators
3. Use `Node Atlas` to understand what each node is for
4. Use `Modules` when you need exact fields, ports, and schema details
